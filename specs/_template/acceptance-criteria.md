# Acceptance criteria

Each item is a checkable, observable statement. If it isn't testable, rewrite it.
Number ACs once; after approval, never renumber them; append new ones instead. Tick an AC (`[x]`)
only with cited evidence: a test name, or a command plus its output line.

- [ ] AC-1: Given <context>, when <action>, then <observable result>
- [ ] AC-2: ...
- [ ] AC-3: ...

## Non-functional
- [ ] Performance: <e.g. p95 under 200ms for endpoint X>
- [ ] Security: <e.g. no new unauthenticated surfaces>
- [ ] Accessibility: <e.g. WCAG AA for new UI>
